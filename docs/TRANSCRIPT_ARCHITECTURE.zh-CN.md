# Transcript 架构

会话视图只有一条投影链和一个滚动写入者：TranscriptStore / ControllerLiveStore → TimelineProjection → TranscriptKernel → 全量 DOM / TanStack 窗口适配器 → TranscriptViewportWriter → 原生滚动容器。

## 投影与展示

完整轮次是稳定块、逻辑锚点与窗口化的共同单位。块键来自后端消息标识，不依赖数组位置、可变正文或历史轮次编号。前插历史、内容更新和流式完成不改变已存在块的标识。

已完成轮次不超过 100 时采用普通 DOM；超过 100 时窗口化较早的已完成历史。当前活动轮及至少两个最新已完成轮保留在普通 DOM。常驻轮只有在离视口至少一个视口、且不拥有锚点、焦点或选择端点时才可进入窗口，迁移前必须一次性记录连续前缀的真实尺寸。TanStack 仅计算尺寸前缀和挂载范围，其自动滚动补偿关闭。

适配器总共最多挂载 40 个已完成块，常驻块和受保护块也占用这一预算。尽量保留运动后方四块作为反向缓冲，其余容量分配给运动前方。候选范围必须覆盖原生视口；候选过期时保留完整可信快照，原生跳转使旧范围也失效时从尺寸账本同步重建。所有路径均不直接写滚动位置。

## 测量与同帧提交

挂载范围、完整前缀、总高度和滚动边距属于同一不可变快照。第三方惰性缓存必须先具体化；不同代际的范围和高度不能混用。

DOM 测量先进入以块键索引的暂存账本。账本只拥有尺寸，输入租约统一由 Kernel 管理。发布时重新读取实际滚动位置，已绘制前缀和实测 DOM 都必须将安全边界放在当前视口之后，并保留一个视口的预备区域。该余量不是原生合成器行程的上限；不能把滚轮意图积分为禁止发布的距离，因为短暂的输入积压也可能超过整个挂载窗口，使未来尺寸冻结到释放时才集中挤压。滚轮、触摸、选择、键盘和原生滚动条输入使用相同的几何发布边界；Kernel 继续在输入租约期间禁止程序滚动抢权。整批尺寸、前缀和位置仍在绘制前共同提交。

释放后，在同一次绘制前提交中发布前缀并恢复首个阅读锚点，取消旧几何任务。后续块按真实内容增长移动，不能冻结所有旧位置造成重叠。绝对定位的挂载块也拥有代际受限的 ResizeObserver，因为内部展开不一定改变投影根高度。不得重新开启 TanStack 自有的测量发布、调用 measure() 清空受保护前缀，或增加平台专用滚动补偿。

## 内核、导航与选择

只有 TranscriptViewportWriter 可以写原生滚动位置。历史前插、问题跳转、恢复、展示设置、选择边缘滚动、输入框尺寸和尾部跟随都提交到 TranscriptKernel。每个事务携带会话、代际和几何版本，并终结为 committed、cancelled 或 expired。用户输入和选择可抢占低优先级事务。已到达的位置可以提交为空操作，不重复写 scrollTop。

异步历史请求拥有源会话身份；导航另外拥有交互版本。旧会话数据可以完成加载，但不能重新取得新视图的定位权限。物理写入的来源保留到匹配的原生 scroll 事件被消费，或不同位移证明用户接管。底部以原生 scrollHeight - scrollTop - clientHeight 不超过 4px 判定。

## 安全展示与生命周期

候选、保留和重建范围均无法覆盖，或必要保护块超出预算时，在绘制前进入共享的全量 DOM 安全展示。使用最后可信前缀保持原生宿主、焦点、选择和阅读位置，不在用户输入期间强制纠偏。两个连续异常会锁定该代际的全量展示，只有更换会话代际才能解除；不会为此强制加载未分页历史或惰性正文。

全量、窗口和安全展示共享观察器与呈现生命周期。所有帧、计时器及观察器通知由可取消、可注入时钟的内核管理；断开后排队的旧通知必须因代际不符而失效。修复应集中在所有权、投影和提交协议，不能靠额外滚动写入者、重试分支或放宽阈值掩盖问题。

## 验证

确定性内核、测量账本和真实 React 几何提交测试覆盖交错时序；真实浏览器验证选择、输入框联动、持续滚动和绘制覆盖；WKWebView、WebView2 和 WebKitGTK 使用各自原生输入宿主。浏览器通过不等于原生宿主通过。详细接口与生命周期说明见英文版本。

获准发布的测量批次同时拥有紧随其后的几何提交。布局 effect 通过状态更新确保提交在绘制前完成，不依赖 TanStack 通知的调度时机。提交必须安装本批次的完整前缀，以及覆盖视口的候选范围或由同一前缀重建的范围。若继续保留旧前缀，已获准的屏幕外高度变化可能延迟到原生滚动将内容带入视口时才出现。非发布事务的过期范围通知仍保留最后一次覆盖视口的快照。

意图变更也由输入所有权控制：没有输入所有者的 scroll 事件可能来自布局约束或迟到的程序写入，因此不能改写逻辑阅读锚点或取消尾部跟随。结构事务使用已有逻辑锚点。触摸惯性和原生滚动条释放继续使用同一个可续期输入租约；跳到底部命令显式结束旧租约。续期不虚构滚动观测，无变化的写入也不会清除待确认的程序滚动来源。
